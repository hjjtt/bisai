# 实训成果智能核查与评价系统
# 部署文档

**文档版本：** V1.0  
**适用环境：** Windows 10+ / Linux (Ubuntu/CentOS)

---

## 一、环境准备

在部署前，请确保服务器满足以下最低配置要求：
*   **操作系统**：Windows 10+ 或 Linux (Ubuntu 20.04+ / CentOS 7+)。
*   **CPU**：4 核+。
*   **内存**：8GB+。
*   **磁盘**：50GB+ 可用空间。

**依赖软件安装：**
1.  **JDK 17**：安装 OpenJDK 17。
    ```bash
    # Linux (Ubuntu/Debian)
    sudo apt install openjdk-17-jdk
    # Linux (CentOS/RHEL)
    sudo yum install java-17-openjdk-devel
    # Windows: 下载并安装 Eclipse Temurin 17 (https://adoptium.net)
    java -version
    ```
2.  **MySQL 8.0**。
3.  **Nginx**：用于托管前端静态资源。

---

## 二、后端部署

### 2.1 数据库初始化
1.  登录数据库执行建表脚本：
    ```bash
    mysql -u root -p < backend/src/main/resources/schema.sql
    ```
2.  初始化默认管理员账号 (脚本中已包含)。

### 2.2 配置文件修改
编辑 `backend/src/main/resources/application.yml` (或打包后通过启动参数覆盖)：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bisai?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: ${DB_PASSWORD:123456}
    driver-class-name: com.mysql.cj.jdbc.Driver
  ai:
    openai:
      base-url: https://api-inference.modelscope.cn   # Spring AI 用，不带 /v1
      api-key: ${AI_API_KEY}
      chat:
        options:
          model: Qwen/Qwen3.5-35B-A3B
      embedding:
        options:
          model: damo/nlp_corom_sentence-embedding_chinese-base

# 业务层 AI 配置 (ModelScope)
ai:
  base-url: https://api-inference.modelscope.cn/v1
  api-key: ${AI_API_KEY}
  model: Qwen/Qwen3.5-35B-A3B
  fallback-model: stepfun-ai/Step-3.7-Flash
  embedding-model: damo/nlp_corom_sentence-embedding_chinese-base
```

### 2.3 启动服务
```bash
# 方式 1: 直接运行 jar 包 (生产环境推荐)
java -jar -Xms1g -Xmx2g backend-1.0.0.jar

# 方式 2: 指定配置文件
java -jar backend-1.0.0.jar --spring.config.location=./application-prod.yml
```
*验证：访问 `http://localhost:8080`，返回 JSON 即成功。*

## 三、前端部署

### 3.1 开发模式启动 (本地调试)
```bash
cd frontend
npm install
npm run dev
```
启动后访问 `http://localhost:3002`（见 `vite.config.ts`，`strictPort: true` 固定 3002），已自动代理 `/api` 到后端 `http://localhost:8080`。

### 3.2 构建前端 (生产部署)
```bash
cd frontend
npm run build
```
构建产物位于 `dist/` 目录。

### 3.3 Nginx 配置
将 `dist/` 下的文件复制到 Nginx 目录 (如 `/usr/share/nginx/html`)。
配置 `nginx.conf`：
```nginx
server {
    listen 80;
    server_name localhost;

    # 前端静态资源
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 四、部署补充说明

### 4.1 PDF/Word 导出字体
*   Linux 服务器若缺少中文字体，导出 PDF/Word 可能出现方块。
    *   Ubuntu：`sudo apt install fonts-wqy-microhei`
    *   CentOS：`sudo yum install wqy-microhei-fonts`
    *   或在 `backend/src/main/resources/fonts` 目录下放置 `.ttf` 字体文件。

### 4.2 离线部署模式 (无外网)
若服务器无法访问互联网 (无法调用 ModelScope)：
1.  **AI 能力降级**：系统支持”纯人工评分模式”，不影响上传、查看和打分功能。
2.  **本地模型**：可部署 Ollama + Qwen2.5，修改 `ai.base-url` 指向本地端口 (如 `http://localhost:11434/v1`)。

## 五、常见问题排查

*   **启动报错 `Connection refused`**：检查 MySQL 是否启动及 `application.yml` 密码是否正确。
*   **AI 调用失败**：检查服务器能否访问外网，或 API Key 是否过期。
*   **中文乱码**：确保数据库字符集为 `utf8mb4`，且应用层设置了 UTF-8 编码。
